# Original R32 provider refusal controls

Source-only successor of immutable `08ebe4cc`. No build, provider worker, Metal
worker or game has run. Five fresh ordinary-Mac-provider Facts are prepared in
`MetalTextureMaterializationTests.R32OriginalRefusals.cs`; these are separate
from genuine managed rows and from actual Metal/status4 numerical qualification.

Each row uses real Mac SharedBackingViews, continuously owned original hole,
cold production full original mapped M0 copy and protected observation. It never
manufactures opaque mapping metadata or prearms the tracker. Architecture,
framework and kernel/ledger page geometry are required; logical provider page
size is reported separately. `SHARPEMU_TEST_REQUIRE_R32_ORIGINAL_REFUSAL=1` and
`SHARPEMU_METAL_SELECTED_NATIVE_REUSE=1` enable the rows. Each must run in a fresh
ARM64 or x64 worker bounded60s, with zero skips and source/DLL closure checked.

The physical-overlap row maps a distinct virtual M1 prefix into the SAME real
backing, with M1's source offset equal to M0's physical source offset. It captures
that M1 through production CreateTextureSnapshots and invokes public Submit.
Both original provider mappings remain current; rejection must be based on the
actual source physical overlap, not virtual address equality.

Mapping replacement unmaps/remaps the same original owned view; rights change
uses actual provider ChangeAccess; session change invokes actual selected-owner
retirement. They never refresh the original M0 snapshot or mapping. Public Submit
must reject before installing any pending work, advancing any completed sequence,
or allocating native resources. A native-only global output makes the read-only
dispatch reach actual admission without supplying a guest writeback destination.
The copied-pixels row accepts the faithful with-copy association and rejects a
replacement pixel array; rejection cannot install the opaque original proof.

All rows assert zero ordinary source reads, empty native selected-image registry,
zero admitted/pending work and unchanged completion metadata. They never Drain,
create a Metal device/encoder, run a shader, or claim successful GPU completion.
The source fact marker explicitly states ordinary-provider-only/no-Metal-status.

Cleanup consumes the unadmitted M1 seed's exact original watch once, releases the
fixture queue state, attempts all tracker and view cleanup, and frees holes only
after known view cleanup. Uncertain cleanup quarantines both owned holes, backing,
memory and seed; the original failure remains primary. Old `08ebe4cc` source and
its separate full native transport fixture remain unchanged.
