# Demon’s Souls selected-copy attempt diagnostic

This is an isolated diagnostic successor to `9e3adfcb8ba79e552d1009a3986e3028b449dc66`. The actual 60-second Demon’s Souls run remained black with zero guest frames; shutdown exposed the worker failure “Metal selected storage mip changed during all three owned-copy attempts.” The failing compute shader was `8A02D692EE458D12`, with sampled-read and storage-write descriptors at `7092C80000`. The original run is `artifacts/runs/20261008-231452-ds-volume-publication-watch-9e3adfcb`; its inputs remain unchanged.

Set `SHARPEMU_METAL_SELECTED_COPY_DIAGNOSTICS=1` before process startup. The ordinary selected-mip producer emits at most 64 `selected-copy-attempt` rows. Each row records the actual optional-copy result, whether it returned an original mapping, the existing provider-currentness decision, source address/byte count, and whether complete legacy reading was used. It also records the original snapshot/token/session/epoch and the existing ordered read-snapshot → seed → token checks. `copy-refused`, `read-generation-changed`, the specific seed-veto reason, or `content-token-changed` identifies the original rejecting branch. `pre-registration-qualified` only identifies those checks passing; later registration and native admission can still refuse.

An additional bounded `[WT][SELECTED-COPY]` row samples the current tracker owners, dirty flags, identities, generations, extents, arm epoch and cached source/sequence/first-fault metadata. A supplied first invocation of zero is uncorrelated: it cannot distinguish managed pre-notification from startup/programmatic recovery. A missing published first-fault record is not evidence that no write happened.

The original snapshot/token and actual decision outputs are retained values. Optional later mapping/watch/token/tracker samples are explicitly non-atomic and may differ because of intervening work. They do not certify writer completion, native/raw/JIT coverage, mapping lifetime, or permission restoration. No timestamp, signal hook, dirty consumption, token refresh, retry policy, epoch exception, or fallback rule is added. Provider and tracker diagnostic queries run outside the presenter gate; default-off exits before extra queries, counters and formatting. Optional formatting/sink failures are caught without replacing the producer error.

Source qualification is pending. Existing meaningful regressions are the 14 managed selected-mip rows, five selected admission-diagnostic rows and 38 R16 selected-mip rows, for 57 GPU managed rows. The two `SelectedMipNativeStoreLoadPreservesEveryOtherSelectedTexelAndGuestNeighbor` rows and the separate R16 native fixture are excluded. The small-linear baseline `ActualStorageSnapshotKeepsOnlySelectedBaseMipWhileResourceHasMoreLevels` is an additional one-row Libs regression. No new mirror tests are added for logging. Exact selectors and source-derived case identities are archived separately before any build grant.
