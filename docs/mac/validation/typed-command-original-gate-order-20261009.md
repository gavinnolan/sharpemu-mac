pending receipt fields/work references, enqueued sequence, pending count and
exact taken work/sequence. Same original provider checks run outside the gate.

that reached inventory. The old locked-only cohort seam has no such inventory

classification; other closed operation kinds and arbitrary callbacks remain
unknown. Complete original physical disjointness and existing native owner,

This inventory is per-call reached-query provenance, not a persistent Current
cache or a new mapping lifetime capability. Its safety against a later mapping

can write only the original physical destination or refuse, never a younger
mapping. Unknown transaction ownership remains process-rooted and further
certified writes refuse. No native resource retain is acquired by the new
inventory snapshot itself.

Older non-typed native-color provider checks are outside this narrow change and
retain their previous source behavior. This document does not claim a general
presenter/provider lock-order audit or hidden-provider gate qualification.
