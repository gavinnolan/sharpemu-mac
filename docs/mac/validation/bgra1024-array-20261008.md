# Finite captured 1024² BGRA storage array

Captured a8c SH/Octopath/Oregon descriptors share raw words
`[addressWord,C3800000,00FFC0FF,D1B00F2E,0,00700000,0,0]` with address words
`80102E00`, `80303000`, `801C6F00`. The native admission is only the complete
matching raw8,64KiB-aligned origin,1024×1024/pitch1024,one layer/base mip0,
type13/mode27,RGBA8Unorm unified56/data10/number0,F2E/PERF7,compiled Float
write-only 2D-array storage shape. Reads/read-write,other selectors,dimensions,
layers,mips,flags,metadata and numeric classes remain outside this addition.
The singleton qualifiers and shared tiling equations are unchanged.

The owned physical slice and linear seed each cover4,194,304 bytes. A complete
successful detile is required; there is no raw-as-linear or zero-filled failure
recovery. Native texture type remains2DArray even with one layer,format70,
usage ShaderRead|ShaderWrite. Existing transactional materialization cleanup,
full extent tracking,view validation and source/dirty semantics are retained.

The independent public AMD AddrLib driver is pinned to PAL
`c5e800072a32f68b6ccc4422936d96167c6e0728`,Navi21/GFX10.3 rev0x28,
GB_ADDR_CONFIG0x344,32bpp/single-sample/TEX2D,pipeBankXor0/noMetadata.
It produces128² blocks,8×8 blocks,4MiB surface/slice,64KiB alignment and zero
mip/macro/tail offsets. Every1,048,576 byte address matches the existing
GnmTiling16-pipe/8-packer model; full offset SHA256 is
`f9547a1fc8de057f80dfe2b8bdcd7c66a5b16d3ec6866dd114f03e5221eca964`.
Actual GetDetileParams/TryDetile/DetileWithParams agree for every texel and all
4MiB of coordinate-distinct seeded bytes on ARM64 and Rosetta.

Topology limitation is material: initial0x244 uses four packers and differs at
(32,0):3072 rather than2048; its full offset SHA is
`5bb28f2d63af4a071a5c8b9b767a411569a7140c10dca4151ac5341f136f5ec8`.
The equation index67 is identical while equation contents differ. REmu/Kairo's
generated render equation is also different. This is qualification under the
existing SharpEmu model,not measured PS5 topology or general mode27 support.
Fixtures retain both geometry outputs and block-boundary samples. CPU/GPU
agreement using one shared equation alone would not establish this layout.

Managed coverage includes all coordinates/full detiled bytes,three actual raw
replays,owned full-seed mutation isolation,successful all-zero seed,short read,
typed live-view mismatch,raw/compiled near-misses and incomplete/unstable owned
payload rejection. An initial control incorrectly changed both descriptor and
raw into type12 and expected the existing type13-only producer guard to reject
before reading; that failed83/84 run is retained. The corrected detached raw
type mismatch verifies the new admission boundary without rewriting other
existing producer policies.

Four native fixtures are compiled for translated MIMG stores at nonzero
interior and last-pixel coordinates,plus out-of-width1024 and layer1 negatives.
They compare all seeded and post-store native pixels,distinct physical RGBA
versus logical BGRA Float channels,and the kernel output-buffer readback.
Read-only sampled views are explicitly created by the fixture; this does not
qualify production sampled-alias selection. Original tiled guest bytes stay
unchanged apart from an explicit post-capture mutation. There is no claim of
GPU texture publication back into tiled guest RAM or changed CPU debt/coherence.
RequireDevice0 only checks codegen; native execution needs the serialized grant.
Integration and affected-title replay remain separate acceptance steps.
