## Boundary and authority

`GuestTargetOf` already has the actual normalized `ColorTargetResolution` and
original `ColorTargetWords`. `MetalColorMipPlacement.Project` returns unchanged
for MaxMip0; therefore a regular image can reach native construction without
either selected-color or storage/display provenance. Cohort refusal is correct.

The separate candidate retains mapping-only facts before acceptance and
native construction: exact selected CPU reader, provider, first session, raw CB

The discarded bounded probe is not upload data or observed content. This record
never grants a protected token, publication, native borrow, freshness, canonical

Supported scope is single-mip, single-layer, single-sample Color2D without
metadata/stencil/block compression, within finite allocation/image bounds and
the existing Metal render-format policy. Validate supplied normalization against

## First-owner lifecycle

A detached preparation owns a first capture until actual queue acceptance.
Acceptance consumes that exact preparation once and retains its original for
the pending target before any GPU write. A later target may reuse only an
already known current original with identical raw words/layout/domain/session;
it cannot replace it with a younger observation or adopt an existing untracked
native image. Cancellation releases only known preparation ownership.

Native image reuse/installation checks the exact accepted original before
effects and after native construction. The live image holds the same original.
The cohort checks pending targets, live images and retained retired records
using complete provider physical segments, never virtual-address separation.
Replacement, unavailable source, stale mapping, unknown cleanup, overflow or
physical overlap remains a strict refusal. Original metadata remains rooted
through an uncertain native release; it cannot disappear as known cleanup.
No retry, new capture or guessed mapping is available at drain time.
